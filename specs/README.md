# Test Plans (specs/)

This directory holds **Markdown test plans** generated by the Playwright Planner agent.

## Workflow

1. **Plan** — Ask the Planner agent to explore the app and generate a test plan:
   > "Use the Playwright Planner to explore SauceDemo and create a test plan for the cart flow"
   
   The plan will be saved here as `specs/saucedemo-cart-plan.md`.

2. **Review** — Read and refine the generated plan. Add/remove scenarios as needed.

3. **Generate** — Ask the Generator agent to convert the plan into test files:
   > "Use the Playwright Generator to create tests from `specs/saucedemo-cart-plan.md`"
   
   Tests will be created in the appropriate `tests/<project>/` directory.

## Naming Convention

Plans follow this pattern:
```
specs/<project>-<feature>-plan.md
```

Examples:
- `specs/saucedemo-checkout-plan.md`
- `specs/anvesha-search-plan.md`
- `specs/api-users-plan.md`
